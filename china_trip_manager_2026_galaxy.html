갤럭시 설치 · 설정 안내

갤럭시(삼성 인터넷 · Chrome) 전용 안내입니다. 데이터는 이 휴대폰에 저장되며, 홈 화면에 추가하면 앱처럼 열립니다.

1. 홈 화면에 추가 (권장: 웹 주소로 열기)

  1. 삼성 인터넷: 하단 ≡ 메뉴 → 현재 페이지 추가 → 홈 화면
  2. Chrome: 우측 상단 ⋮ → 홈 화면에 추가 (또는 앱 설치)
  3. 바탕화면의 중국출장2026 아이콘으로 실행

2. 파일로 바로 여는 경우

카카오톡에서 받은 파일 → 내 파일 → 다운로드(Download) → 파일을 눌러 삼성 인터넷으로 열기. 화면 위에 빨간 경고가 뜨면 이 방식에서는 저장이 안 되는 것이니 웹 주소로 열어 주세요.

3. 중국어 음성 미리 받기

설정 앱 검색창에 ‘글자 읽어주기’ → 기본 엔진 옆 ⚙ → 음성 데이터 설치 → 중국어 다운로드. Wi-Fi에서 받아 두면 비행기 모드에서도 재생됩니다.

4. 저장 파일 위치

CSV 정산 파일·백업 JSON은 내 파일 → 다운로드 폴더에 저장됩니다. 카카오톡 파일 전송에서 바로 고를 수 있습니다.

출국 전 점검

· 한국에서 홈 화면 추가 후 한 번 실행

· 비행기 모드로 바꾸고 아이콘을 눌러 열리는지 확인

· 웹에 올릴 때 sw.js를 같은 폴더에 함께 올리면 오프라인 실행이 확실해집니다

· 삼성 인터넷 다크 모드에서 색이 이상하면 ≡ 메뉴 → 다크 모드 끄기

온라인 필요: 최신 환율, 고덕·바이두 지도, 입국신고 사이트

중국어 음성이 안 나올 때

  1. 설정 앱 검색창에 ‘글자 읽어주기’ 입력
  2. 기본 엔진(삼성 TTS 또는 Google) 옆 ⚙ 누르기
  3. 음성 데이터 설치 → 중국어 다운로드 → 설치
  4. 이 앱으로 돌아와 아래 테스트 재생

메뉴 위치 예: 설정 → 접근성 → TalkBack → 설정 → 글자 읽어주기 (기종·버전에 따라 다를 수 있음). Wi-Fi에서 미리 받아 두면 비행기 모드에서도 재생됩니다. 미디어 볼륨도 확인하세요.

음성이 안 나와도 [크게 보여주기] 화면을 상대방에게 보여주면 됩니다.
