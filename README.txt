[2026 중국 출장 매니저 - 웹 업로드용 묶음]

이 폴더의 파일 5개를 웹(https) 주소의 "같은 폴더"에 그대로 올리세요.
 - index.html                          : 기본 주소로 열리는 화면 (공용 버전과 동일)
 - china_trip_manager_2026.html        : 공용 버전 (아이폰·갤럭시)
 - china_trip_manager_2026_galaxy.html : 갤럭시 전용 안내 버전
 - sw.js                               : 오프라인 실행용 (비행기 모드에서도 아이콘으로 열림)
 - README.txt                          : 이 안내문 (올리지 않아도 됨)

사용 순서 (출국 전, 한국에서)
 1. 회사 웹서버, Netlify Drop, GitHub Pages 등에 폴더째 업로드
 2. 휴대폰에서 주소 열기
    - 아이폰: Safari → 공유 버튼 → 홈 화면에 추가
    - 갤럭시: 삼성 인터넷 ≡ 메뉴 → 현재 페이지 추가 → 홈 화면
             (크롬: ⋮ → 홈 화면에 추가)
 3. 홈 화면 아이콘으로 한 번 실행 (이때 오프라인용으로 저장됨)
 4. 비행기 모드로 바꾸고 아이콘을 눌러 열리는지 확인

주의
 - sw.js는 반드시 HTML 파일과 같은 폴더에 있어야 합니다.
 - 파일 이름을 바꾸지 마세요 (sw.js.txt 처럼 확장자가 붙으면 작동하지 않습니다).
 - HTML 파일만 단독으로 쓸 때는 sw.js가 필요 없습니다.
